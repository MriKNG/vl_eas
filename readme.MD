# Valiant - Emergency Alert System

## Features

- Automatic 15, 5 en 1 minute alerts compatible with txAdmin
- Custom alert with command /eascustom
- Test alert with command /eastest
- Ragdoll and weather effects enabled and disabled through config
- Change alert messages, titles, sounds, volumes through config
- Compatible with qb-phone / lb-phone and roadphone

## Dependencies

- qb-core
- interact-sound
- phone (qb-phone / lb-phone / roadphone)
